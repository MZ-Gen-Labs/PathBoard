# PathBoard 実装・検証状況

更新日：2026-10-14 / 版：0.1.0（開発版）

## 実装した機能

- SwiftUI + NSOutlineViewの2×2画面。登録、表示名変更、解除、隠し項目表示、ツリーの遅延読み込み、現在位置表示。
- パネル見出しをドラッグして4つの位置を入れ替え。位置と各パネルの状態はワークスペースに保存。
- 現在の場所にフォルダを作成し、選択中のフォルダ（現在位置）の名前を変更。保存先ルートは改名不可。同名項目を上書きせず、登録ルート内でのみ操作。
- 空の4パネルの新規ワークスペース作成と、現在の状態を複製して保存する操作を区別。分割比率、展開状態、現在位置、スクロールを含む保存・切替・名前変更・削除。
- 内部ドラッグ型によるパネル間転送、ドロップ後のコピー／移動選択、衝突時の別名／スキップ／キャンセル。
- 同一ツリー内のフォルダ間ドラッグ転送と、選択したフォルダを確認後にシステムのゴミ箱へ移す操作。
- SHA-256と必要属性による検証、上書きなし確定、元と先の再確認、元のゴミ箱保全。
- ジョブの直列処理、キャンセル要求、永続履歴、再起動後の要確認表示、条件付きの取り戻し。
- MIT同梱、arm64アプリ、署名なしPKG、チェックサム、GitHub Actionsと正式Releaseの受け入れゲート。

## 仕様から具体化・変更した点

1. 移動と移動の取り戻しでは、検証後の元を永久削除せず、システムTrashへ保全する。保全先の内容も再検証する。保全失敗は両方を残す。ゴミ箱の容量消費は増える。
2. パッケージ、リンク、特殊ファイルを含むトップレベル項目は停止する。1属性16MiBを超える場合も停止する。履歴に属性本文を置かずハッシュを置く。
3. OSが実行するコピーやFile Provider取得中はキャンセルの実処理が遅れる場合がある。UI側の要求は受け付け、コピーから戻ったら削除前に停止する。
4. 取り戻しを始めた履歴は先に要確認として保存する。曖昧な中断の自動再実行はしない。未着手のスキップ・キャンセルは再試行できる。
5. 登録先が移動した場合はbookmarkで再参照する。バージョン更新時のOS権限継続は、署名なし配布のため別Mac試験で確認する。
6. 受け入れゲートはソース内容のSHA-256指紋で対象版を照合する。ゲート記録自身、実施記録、受け入れ証跡は指紋から除外し、自己参照するコミットSHAを要求しない。

## 再実行

```sh
swift test --disable-sandbox
bash scripts/build-pkg.sh
```

実クラウドテストは、テスト専用領域を作成できるルートをJSONで渡した時だけ実行する。ファイルにはサービス名と絶対パスを指定する。個人のパスをGitへコミットしない。

```sh
PATHBOARD_CLOUD_ROOTS_FILE=/private/tmp/pathboard-cloud-roots.json \
  swift test --disable-sandbox --filter CloudSmokeTests
```

受け入れ完了後、対象のソース指紋を取得してゲート記録を更新する。

```sh
python3 scripts/check-release-gate.py --fingerprint
```
